# Task Manager

A simple web app to add, complete and delete tasks.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter: All / Active / Completed
- Dark mode toggle

## Built with
HTML, CSS, JavaScript

## Live demo
https://lacky-369-prsad.github.io/task-manager

## How to run
1. Clone the repo
2. Open index.html in your browser
