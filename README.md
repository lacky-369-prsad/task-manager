# Task Manager

## What it is
A simple web app to manage daily tasks. You can add tasks, mark them as completed, delete them and filter them.

## Why I made it
I made this project to practice HTML, CSS and JavaScript, and to build a small tool that is useful in daily life.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks: All, Active and Completed
- Dark mode toggle
- Works on mobile and desktop
